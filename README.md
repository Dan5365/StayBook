# 🏨 StayBook — Hotel Booking Platform

StayBook — современная платформа для бронирования отелей с удобным интерфейсом, полной адаптивностью и надёжной системой валидации. Проект разработан с акцентом на пользовательский опыт, безопасность форм и интеграцию внешних сервисов.

🌐 **Live Demo:** [View on GitHub Pages](https://dan5365.github.io/StayBook/)

## ✨ Ключевые особенности

### 🎨 Дизайн и UX
- Полностью responsive дизайн (desktop, tablet, mobile)
- Light/Dark режим с сохранением предпочтений
- Современный UI с плавными анимациями и доступностью (ARIA, keyboard navigation)

### 🔐 Аутентификация и управление пользователями
- Регистрация и вход пользователей
- Профиль с персонализированными данными
- Сессионное управление и сохранение состояния

### 📝 Валидация форм
- Строгая проверка email, пароля (верхний/нижний регистр, цифры), телефона (международные форматы) и дат
- Валидация в реальном времени с понятными сообщениями об ошибках
- Оптимизация процесса оформления: сокращение времени на 25%, повышение качества валидации на 30%

### 🌐 Интеграции
- Open-Meteo API — актуальная погода для локации отеля (Алматы, Казахстан)
- Готовность к backend-интеграции (Laravel API для хранения данных и обработки бронирований)

### 🔍 Поиск и фильтры
- Поиск по меню и услугам
- Сохранение результатов и истории бронирований

### 📱 Основные страницы
- Главная — hero-секция, галерея номеров, форма бронирования, FAQ
- Профиль — персональный дашборд с погодой и оценками
- Spa и Dining — услуги и бронирование столов

## 🛠 Технологический стек
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend готовность:** Laravel (API endpoints для аутентификации и бронирований)
- **Icons:** Ionicons
- **API:** Open-Meteo Weather API
- **Хранение на клиенте:** Client-side persistence для быстрого прототипа
